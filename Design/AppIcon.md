# Bewie album artwork icon

The active icon uses the existing album sleeve at
`Bewie/Assets.xcassets/LaunchAlbumCover.imageset/front-laetitia.png`.
`tools/generate-album-icons.swift` renders it into the 1024-pixel native icon
without recoloring or adding text. A centered aspect-fill resize handles the
slight source aspect-ratio difference. The source artwork stays unchanged.

`Bewie/AppIcon.icon` is shared by iOS, Mac Catalyst and Watch. Default and dark
use the same original-color image; clear and tinted appearances are generated by
the native Icon Composer system. No rounded corners or glass effects are baked
into the image. All six appearances for generations 26 and 27 are exported under
`Design/Icons/iOS-26` and `Design/Icons/iOS-27`.

Messages uses all twelve required opaque icon sizes. TV uses the complete sleeve
centered on chalk to fit the rectangular tile without stretching or cropping the
photograph; its foreground layer is transparent. Top Shelf retains its existing
album artwork. Both rectangular icon generator entry points call the shared
album generator.

Regenerate:

```sh
swift tools/generate-album-icons.swift
python3 tools/export-icon-previews.py
swift tools/make-icon-contact-sheet.swift
```

The previous original-color logo icon is archived at `Design/Icons/Logo.icon`.
The inherited pearl icon remains at `Design/Icons/InheritedPearl.icon`.
The private pearl/map asset is unchanged.

The contact sheet is `Design/Icons/Bewie-iOS-appearances.png`. Clear previews use
Icon Composer’s neutral environment; the sample purple tint is system-controlled.
